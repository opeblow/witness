# Getting help

| You want to                         | Go to                                                                              |
| ----------------------------------- | ---------------------------------------------------------------------------------- |
| Ask how to use or integrate Witness | GitHub Discussions, or an issue labelled `question`                                |
| Report a bug                        | A new issue using the bug report template                                          |
| Suggest a feature                   | A new issue using the feature request template                                     |
| Report a vulnerability              | GitHub private vulnerability reporting, as described in [SECURITY.md](SECURITY.md) |
| Report a code of conduct concern    | A private vulnerability report marked "Conduct", which only maintainers can read   |

Before opening an issue, check [docs/](docs) and the existing issues. For anything involving a specific capture, include its Witness id or content hash, and never include private keys or device key backups.

Witness runs on the Portaldot V3 testnet. For problems with the network itself, such as RPC availability or testnet tokens, use the [Portaldot Discord](https://discord.gg/portaldot).
